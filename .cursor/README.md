# `.cursor` deste meta-repo

Contexto do agente quando o workspace é `~/git`. Uma rule por assunto.

| Rule | Problema que evita |
| --- | --- |
| `rules/purpose.mdc` | Tratar este repo como app, ou aplicar rules de Olie/Laravel ao editar a VM |
| `rules/why-it-exists.mdc` | Mudança sem o motivo — o relato fica em `HISTORICO.md` |
| `rules/layout.mdc` | Não saber por que uma pasta ou script foi parar aqui |
| `rules/shell.mdc` | Script sem cabeçalho, ou host e guest no mesmo arquivo |
| `rules/overlays.mdc` | Commit de secret, ou overlay aplicado no remoto da empresa |
| `rules/meta-repo.mdc` | Não saber qual projeto está ativo, nem como o MCP e o patch dos clones entram na janela |
