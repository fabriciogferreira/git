## 4. Problema observado (alinhamento)

- O card pede alinhamento **horizontal** entre o **início do título** e o **início das opções da toolbar**.
- No layout atual do código: `.card-header` usa `padding: 0 2.25rem`; a toolbar (`.toolbar-menu`) usa `padding: 0.25rem`.
- Resultado típico do desalinhamento: título começa mais à direita que o primeiro botão da toolbar (ou o inverso, conforme o padding efetivo no tema).
- Mensagem do card (media texto) confirma o critério:
  - Correto: título e Btn-1 na mesma coluna esquerda.
  - Incorreto: título indentado e botões colados à esquerda (ou vice-versa).
  - Soluções sugeridas no card: padding-left nas opções **ou** ajustar padding do título.

## 5. Evidências para o coding agent

- Componente: `packages/ui/src/components/forum/BaseForum.vue` (título em `.card-title`; editor com `always-show-toolbar` + `toolbar-align="start"`).
- Toolbar: `DefaultToolbarMenu.vue` (`.toolbar-menu { padding: 0.25rem; }`).
- Tema Metronic: `.card .card-header { padding: 0 2.25rem; }`.
- Preferência do card: **padding nas opções de texto** para alinhar com o título (escopo caderno; evitar mudar toolbar global sem necessidade).
